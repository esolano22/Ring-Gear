Ring Gear es una aplicación web de comercio electrónico dedicada a la venta de guantes y equipamiento de boxeo.

El proyecto incluye una tienda online con catálogo de productos, carrito de compra, gestión de usuarios y pedidos, además de un panel de administración para gestionar la tienda.

Tecnologías principales: Java, Spring Boot, Hibernate/JPA, Thymeleaf, HTML, CSS y JavaScript.
